# ShortlistMe

## Overview
ShortlistMe is a web platform that helps users instantly create a professional portfolio from their resume or basic details.

Instead of spending hours designing and writing a portfolio, users can simply upload their resume or fill in their details, and ShortlistMe will generate a clean, shareable portfolio for them.

---
## Problem We Are Solving
Creating a portfolio can be:
- Time-consuming  
- Difficult for non-technical users  
- Repetitive (same information rewritten again and again)

Many students and professionals struggle to present themselves effectively online.

---

## Our Solution
ShortlistMe simplifies this process by:
- Automatically generating a portfolio from a resume  
- Providing ready-to-use templates  
- Allowing quick customization  
- Giving users a shareable portfolio link  

This helps users focus on their skills instead of design and setup.

---

## How It Works
1. User signs up or logs in  
2. User uploads a resume or fills in details manually  
3. The system processes the data  
4. A portfolio is generated automatically  
5. User can edit and customize it  
6. A shareable link is created
